# HealthyMeal AI

Chatbot asisten nutrisi pribadi yang memberikan rekomendasi menu makanan sehat menggunakan Google Gemini AI.

## 📝 Deskripsi

HealthyMeal AI adalah chatbot interaktif yang bertindak sebagai ahli gizi virtual. Chatbot ini memberikan rekomendasi makanan sehat, saran nutrisi, dan menjawab pertanyaan seputar pola makan dengan bahasa yang santai, positif, dan mudah dipahami.

## 🎯 Target Pengguna

Orang yang ingin mendapatkan informasi dan rekomendasi menu makanan sehat untuk gaya hidup yang lebih baik.

## ✨ Fitur

- Chat interaktif dengan AI
- Rekomendasi menu makanan sehat
- Konsultasi nutrisi berbasis percakapan

## 🛠️ Teknologi

**Backend:**
- Node.js & Express.js
- Google Gemini AI API
- CORS untuk komunikasi client-server

**Frontend:**
- HTML, CSS, JavaScript (Vanilla)
- Fetch API untuk komunikasi dengan backend
